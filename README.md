# KrustyK's COK Bot Farm

Phone-first Android 14 automation framework for one Main/VIP profile and ten farm profiles.

Current build contains the complete safe foundation: 11 persistent profiles, per-account permissions, resource priorities, reserves/reinvestment policy, economy dashboard framework, Accessibility gestures, floating emergency controller, logging, Android screenshot capability declaration, and GitHub Actions build/lint.

## Calibration requirement
A live Clash of Kings UI cannot be safely hard-coded without seeing the current screens on the target phone. Therefore game-specific autonomous taps intentionally remain blocked until the X-Plus is used to calibrate screen recognition. This prevents an unknown screen from causing destructive taps.

No anti-cheat evasion, device spoofing, CAPTCHA/verification bypass, or automated mass Google-account creation is included.
